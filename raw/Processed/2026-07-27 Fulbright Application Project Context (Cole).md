## Application Components (due by Aug 21 for Duke review)
1. Fulbright Online Application account (apply.iie.org), Duke selected as affiliated institution
2. **Statement of Grant Purpose** (max 2 single-spaced pages) — the core project proposal
3. **Personal Statement** (1 single-spaced page) — personal/intellectual narrative
4. **Three Short Answers** — Flexibility & Adaptability, Community Engagement, Impact of Fulbright Award
5. Official transcripts (Duke + any other institutions)
6. **Three letters of recommendation** (registered in portal) — plan: JHTV supervisor, a Duke professor, one more for adaptability
7. Affiliation/invitation letter from host institution (encouraged, not strictly mandatory — USIEF/AMINEF/etc. can help place if none secured)
8. Language Self-Evaluation Form (optional, strengthens application if committing to language study)

**Items 2-4 are the ones my aunt can help with (writing/narrative review).** Items 6-7 depend on other people's response times.
