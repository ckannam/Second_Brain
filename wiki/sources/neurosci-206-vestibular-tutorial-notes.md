*Neuroscience* 7e **Ch 11**. Text outline of the **5 Key Concepts (11.1–11.5)** with **learning objectives**, a
roman-numeral outline (peripheral labyrinth → otolith mechanism → semicircular-canal mechanism → central processing →

**Highlights captured in the note:** shared **hair-cell transduction** with the cochlea (bend toward tallest →
depolarize; endolymph/perilymph; **Scarpa's ganglion**, CN VIII); **otoliths = otoconia-loaded maculae** sensing
**tonic tilt + linear accel** (utricle = horizontal, saccule = vertical, split across the **striola**); **semicircular
canals = cupula in the ampulla** sensing **rotational ACCELERATION not velocity**, in **push-pull pairs**; **VOR
circuit** (vestibular nucleus → contralateral abducens → MLF → oculomotor) + **nystagmus** (slow VOR phase + fast reset);
**lateral (ipsilateral extensor) vs. medial (bilateral neck) vestibulospinal tracts**; **VPC thalamus →
parieto-insular vestibular cortex** (multimodal, no dedicated primary area); autonomic/nausea + motion-sickness hook.
