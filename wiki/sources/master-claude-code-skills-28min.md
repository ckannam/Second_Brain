# Master 95% of Claude Code Skills in 28 Minutes

**Thesis:** A ground-up primer on Claude Code **skills** — what they are, why they matter, their anatomy, and a live build.

## Key points
- **Anatomy of a skill**: a folder with a markdown instruction file (name + description that controls triggering) plus optional **reference files**.
- How Claude decides **when** to use a skill (the description is the trigger surface).
- The **feedback cycle**: build a skill when you find yourself repeating the same instructions.
- **Six-step skill-building framework**; live build; testing, debugging, and common fixes.
