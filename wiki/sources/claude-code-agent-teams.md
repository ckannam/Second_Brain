# How to Build Claude Agent Teams

**Thesis:** **Agent Teams** spin up multiple Claude agents that work in **parallel**, talk to each other, and QA each other's work inside Claude Code.

## Key points
- Enable agent teams; prompt them well; watch them in a **tmux split-pane** view in real time.
- **Agent Teams vs [[claude-code-subagents|sub-agents]]:** teams collaborate/QA in parallel; sub-agents are delegated single-purpose helpers. Choose based on whether tasks need cross-talk.
- Dos/don'ts, key rules, common pitfalls and fixes; when to use teams vs not.
