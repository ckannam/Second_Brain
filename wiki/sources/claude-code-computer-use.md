# Claude Code Just Got Another Huge Upgrade (Computer Use)

**Thesis:** Anthropic added **Computer Use** to Claude Code (research preview) — it can natively control mouse, keyboard, and take screenshots to drive any desktop app.

## Key points
- Demos: sending a file through ClickUp; controlling a Mac remotely from a phone via **Dispatch**; opening a calculator from the phone.
- Enable it in settings; pair with **Dispatch** for phone-based remote control.
- **Limitations:** research preview; browser use has workarounds; reliability caveats.
- Best use cases: automating GUI-only apps that lack APIs.
