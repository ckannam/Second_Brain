# Andrej Karpathy's LLM Wiki, Built in Obsidian + Claude Code

**Thesis:** Walkthrough of building [[andrej-karpathy|Karpathy's]] **LLM Wiki** pattern (interlinked markdown knowledge base maintained by an LLM) in ~5 min, using **Obsidian as the front end** and Claude Code as the writer. **This is the pattern this very vault is built on.**

## Key points
- Ingest an article → LLM writes/updates interlinked wiki pages; query the wiki later; connect multiple projects/wikis.
- Shows the presenter's own wikis: one for YouTube transcripts, one personal second brain.
- **LLM Wiki vs traditional semantic-search [[rag|RAG]]:** the wiki is human-readable, explicitly cross-linked, and improves with curation; RAG is opaque vector retrieval. See [[llm-wiki-vs-rag]].
- Source of the pattern: Karpathy's gist (already ingested as [[llm-wiki-karpathy]]).
