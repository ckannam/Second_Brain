# Gemini Embeddings 2 + Claude Code = Easy Visual RAG

**Thesis:** Google's **Gemini Embeddings 2** natively embeds images, video, and text together. With Claude Code you build a full **visual search engine** without hand-writing chunking/ingestion.

## Key points
- Claude Code handles the whole pipeline: extracts content from images, generates descriptions, builds a **Pinecone** vector DB, wires up a chat app.
- Demos: instruction-manual search, roofing-company search, searching **videos** by content.
- Covers how RAG/embeddings work; current limitations.
- Contrast with the [[llm-wiki-vs-rag|LLM Wiki approach]]: this is classic vector RAG, made turnkey.
