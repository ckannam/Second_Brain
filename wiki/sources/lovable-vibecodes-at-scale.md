# How Lovable vibecodes production software at scale

Fabian Hedin (Cofounder & CTO, [[lovable|Lovable]]) on the difference between vibecoding a
pretty prototype and **running a platform non-developers use to ship production software**.
Software built on Lovable serves **600M+ monthly sessions**.

Systems he walks through:
- A **fleet-learning layer** that catches coding mistakes across all users (organizational
  learning across many sessions — cf. [[agent-memory]] / [[agent-dreaming]]).
- An **[[eval-driven-model-selection|eval loop]] that gates every model release.**
- How Lovable keeps improving itself.

The production-grade end of [[vibecoding]]. Related: [[lovable]], [[website-building-with-ai]],
[[self-healing-workflows]].
