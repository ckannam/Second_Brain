# Skill Issue: Andrej Karpathy on Code Agents & AutoResearch

**Thesis:** (Interview — [[andrej-karpathy]] with [[sarah-guo]].) The state of models, the future of engineering/education/jobs, and Karpathy's **AutoResearch** project where agents close the research loop autonomously. (Channel attribution "No Priors" inferred from Sarah Guo + Conviction references.)

## Key points
- Karpathy: since ~December he's gone from 80/20 to ≪20/80 hand-written vs delegated code — "haven't typed a line of code since December." Describes a state of "AI psychosis" at what's now possible for an individual.
- When waiting on an agent, the instinct is to **parallelize** more work — you become the bottleneck only if not maxing your token spend.
- **AutoResearch**: agents design experiments, collect data, train, and optimize a piece of AI research without a human in the loop.
- Praises **"Open Claude" / OpenClaw** (by "Peter") for sophisticated **memory systems** beyond default context-compaction — ~5 genuinely good ideas in it. (Cross-links the [[claude-code-paperclip-openclaw]] source.)
- Also covers: model **speciation**, jobs-market data, open vs closed models, autonomous robotics, MicroGPT & agentic education.
