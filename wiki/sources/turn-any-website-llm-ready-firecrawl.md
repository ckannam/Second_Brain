# Turn Any Website Into LLM-Ready Data (Firecrawl + Claude Code)

**Thesis:** Use **Firecrawl** + Claude Code to scrape/convert any website into clean LLM-ready data — scraping, branding extraction, site mapping, structured data — in seconds.

## Key points
- Set up the **Firecrawl MCP server** in Claude Code; write a Firecrawl "cheat sheet" + `CLAUDE.md` so the agent knows how to use it.
- Use cases: scraping 200 job listings from a remote board; extracting branding from landing pages.
- Claude Code **self-corrects** its scraping; can run **multiple agents at once**.
- You don't pick endpoints/config — just say what you want.
