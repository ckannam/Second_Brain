# How Anthropic uses Claude in GTM Engineering

Jared Sires went from account executive with **zero coding experience** to "go-to-market
architect," building **CLAFTS / Class (Claude Drafts)** — an AI email assistant on the
Claude API that drafts customer replies in his own voice, built with [[claude-code]].

As a startup AE he managed 600–700 accounts and answered emails until 8–9pm, scouring
Slack, knowledge bases, and Google Docs/Drive. **Class** hooks a system prompt to context
knowledge + pattern matching: enter name/role, generate a system prompt, pull context via a
Google Docs integration (or web URLs / Claude Docs), then "generate draft" on an email.
Claims: saves **2–3 hours/day**, thousands of emails sent. His takeaway — with the technical
barrier dissolving, non-engineers can **design** products and have senior engineers
implement the last stretch.

A concrete instance of the [[ai-native-engineering-org|role-blurring]] Fiona Fung describes.
Full case study: claude.com/blog/how-anthropic-uses-claude-gtm-engineering. Related:
[[ai-executive-assistant]], [[natural-language-coding]].
