# Every Level of a Claude Second Brain Explained

**Thesis:** There are **5 levels** to a Claude Code second brain, from a simple `CLAUDE.md` router up to an always-on autonomous system. The goal is **not** to reach level 5 — it's to find the *lowest* level that solves your pain.

## The 5 levels (using the presenter's real "Herk2" project)
1. **Level 1** — a single `CLAUDE.md` that routes the agent (context + where to look).
2. **Level 2** — organized context files / structured project.
3. **Level 3** — skills and reusable workflows.
4. **Level 4** — sub-agents / delegation.
5. **Level 5** — always-on autonomous system ([[claude-code-scheduled-tasks|scheduled tasks]], loops, self-improvement).

Point: stop re-explaining things and make the agent always know where to look — match the level to the actual problem.
