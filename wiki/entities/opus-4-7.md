# Opus 4.7

A Claude **Opus**-tier model from [[anthropic]], referenced across the July 2026 Code with
Claude batch as the then-newest flagship. In [[production-faster-managed-agents]] it marks
the [[the-capability-curve|capability-curve]] rung where "people clear entire backlogs and
wake to merge-ready PRs." Used in live demos with **effort levels** (low/high/max) in
[[the-thinking-lever]] and to generate HTML design directions in [[how-we-claude-code]];
noted for a much-improved **vision** model over predecessors.

Tier heuristic (from [[picking-the-right-model]]): **Opus** for intelligence, **Sonnet** for
balance, **Haiku** for latency/cost. Predecessors referenced in the batch: [[opus-4-6]],
[[opus-4-5]] (whose release removed the [[context-anxiety]] behavior seen in Sonnet 4.5).
