# Opus 4.5

A Claude Opus-tier model from [[anthropic]]. Referenced in the Code with Claude batch mainly
for one thing: its release **removed the [[context-anxiety]]** behavior that Sonnet 4.5 had
shown (wrapping tasks up early), making the harness mitigations built for that behavior
obsolete — the motivating example for why harnesses must co-evolve with models
([[ship-your-first-managed-agent]]).

Part of the Opus lineage in this vault: [[opus-4-5]] → [[opus-4-6]] → [[opus-4-7]]. Related:
[[claude-managed-agents]], [[the-capability-curve]].
