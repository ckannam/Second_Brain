# Clawdbot

A young **third-party AI agent tool**, positioned as an alternative to [[claude-code]] for always-on personal-assistant use. Distinct from Claude Code (the two are benchmarked head-to-head).

## What sources say
- **Head-to-head verdict:** Claude Code wins overall, but Clawdbot has strengths for advanced users — with notable **security risks**. Src: [[100-hours-clawdbot-vs-claude-code]].
- **As a personal assistant:** the presenter built "Klaus," a proactive 24/7 assistant on Clawdbot. Src: [[i-turned-clawdbot-personal-assistant]].
- **Hosting:** run it 24/7 on a [[vps|VPS]] (Hostinger) instead of a Mac mini. Src: [[set-up-clawdbot-vps]].

Related tools: [[paperclip]], [[openclaw]]. Concept: [[ai-executive-assistant]]. (Note: "Clawdbot" spelling per transcripts; treat as a distinct product, details still emerging.)
