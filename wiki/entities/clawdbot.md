# Clawdbot → now [[openclaw|OpenClaw]]

**Clawdbot is the former name of [[openclaw|OpenClaw]]** — the same open-source, always-on
personal-assistant agent harness by **Peter Steinberger**, not a separate product. It launched as
*Clawdbot* (~Nov 2025) and was **renamed OpenClaw** (~Jan 2026; alias "Moltbot" also appears).
**The canonical page is [[openclaw]]** — read it for the current identity, memory system, and
sources. This page is kept because the July-2026 source videos were clipped under the "Clawdbot"
name and link here.

> **Superseded (2026-07-28):** an earlier version of this page called Clawdbot a *distinct*
> third-party tool "benchmarked head-to-head" against, and "competing" with, OpenClaw. That was
> wrong — they are one tool at two points in time. Corrected via web research 2026-07-28.
