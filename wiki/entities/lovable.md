# Lovable

A [[vibecoding]] platform that non-developers use to ship production software — built on
Lovable serves **600M+ monthly sessions**. Cofounder & CTO **Fabian Hedin** presents
[[lovable-vibecodes-at-scale]].

To run Claude reliably at consumer scale, Lovable built a **fleet-learning layer** (catches
coding mistakes across all users — a cross-session organizational-learning system akin to
[[agent-memory]]/[[agent-dreaming]]) and an **[[eval-driven-model-selection|eval loop]] that
gates every model release.** Represents the production-grade end of vibecoding, versus a
one-off pretty prototype. Related: [[anthropic]], [[website-building-with-ai]], [[omni]].
