# Gemini Embeddings 2

Google embedding model that natively represents **images, video, and text together** (multimodal), enabling turnkey [[multimodal-rag]]. In [[google-rag-gemini-embeddings-2]], [[claude-code]] uses it to build a visual search engine end-to-end (embeddings → [[pinecone]] → chat app) with no hand-written chunking.

Vendor: [[google]]. Related: [[rag]], [[gemini]].
