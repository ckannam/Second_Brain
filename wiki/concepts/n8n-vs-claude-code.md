# n8n vs Claude Code

A recurring debate across [[nate-herk]] sources: node-based automation ([[n8n]]) vs [[agentic-workflows|agentic]] automation ([[claude-code]]).

## Summary of the vault's position
- **Claude Code is winning mindshare** (search + views) and is the higher-leverage thing to learn for 2026. Srcs: [[stop-learning-n8n-2026]], [[is-n8n-dead]].
- **n8n isn't dead** — still a fine beginner on-ramp and useful for deterministic, visual pipelines.
- **Best of both:** Claude Code + n8n MCP = [[self-healing-workflows]] ([[i-will-never-fix-n8n-self-healing]]).
- **Trade-off:** n8n = predictable/brittle; Claude Code = flexible/self-healing but less deterministic ([[agentic-vs-deterministic]]).
