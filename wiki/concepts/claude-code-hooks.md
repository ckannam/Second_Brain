# Claude Code Hooks

User-configured triggers that run on Claude Code events (e.g. play a sound when a session finishes). In [[claude-code-2-scheduled-tasks]], a finish hook is used to get audible notifications for unattended [[claude-code-scheduled-tasks|scheduled tasks]]. Set up by just asking Claude Code to add one. Related: [[claude-code-permissions]].
