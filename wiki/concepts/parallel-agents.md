# Parallel Agents

Running multiple [[claude-code]] agents at once to work faster. Enabled by [[claude-code-agent-teams]] (peers that collaborate + QA, watchable in a [[tmux]] split-pane) and observable via [[pixel-agents]] ([[agent-observability]]). [[andrej-karpathy]] frames the mindset in [[skill-issue-karpathy-sarah-guo]]: when waiting on an agent, parallelize more work — you're only the bottleneck if you under-spend on tokens.
