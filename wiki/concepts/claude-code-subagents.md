# Claude Code Sub-agents

Delegated, single-purpose helper agents spawned by a main [[claude-code]] session to handle a scoped task, then report back. Level 4 of the [[ai-second-brain-levels]].

**Sub-agents vs [[claude-code-agent-teams|agent teams]]:** sub-agents are one-way delegation (parent → helper → result); agent teams are peers that run in [[parallel-agents|parallel]], talk to each other, and QA each other's work. See [[skills-vs-subagents]] for when to reach for a skill instead. For the full decision guide (sub-agents vs teams vs managed-agents), see [[claude-code-agent-teams]]. Covered in [[build-sell-claude-code-course]], [[turn-claude-code-executive-assistant]].
