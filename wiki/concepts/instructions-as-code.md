# Instructions-as-code

Treating an agent's **instructions/skills as version-controlled code**: edited, reviewed, and
**merged like any PR**, so an agent can **improve itself daily** while the team keeps control
(from [[teaching-agents-learn-from-team]]).

Two coupled ideas:
- **Skills that teach agents how to *think*, not what to do** — durable judgment over brittle
  step lists.
- **Close the feedback loop** so team judgment flows back into the agent automatically.

A lightweight, per-team cousin of [[agent-dreaming]] (self-improvement via curated memory)
and [[governed-skills-framework]] (shared, reviewed skills at org scale). Rhymes with
[[running-ai-native-engineering-org]]'s "check the spec into the repo" and
[[claude-md-router]]. Related: [[claude-code-skills]], [[claude-code-memory]].
