# Vibecoding

Building real software by describing intent in natural language and letting an AI agent write all the code — no hand-written code.

- **Proof point:** [[cal-ai|Cal AI]] was vibecoded and sold for ~$100M ([[this-100m-ai-app-cal-ai]]).
- The whole [[build-sell-claude-code-course]] is explicitly "we don't write a single line of code."
- [[andrej-karpathy]]: "haven't typed a line of code since December," delegating to agents ([[skill-issue-karpathy-sarah-guo]]) — see [[natural-language-coding]].

**Production-grade vibecoding** (Code with Claude batch): the hard part isn't the pretty prototype but running a platform non-developers ship on. [[lovable|Lovable]] serves **600M+ monthly sessions** with a fleet-learning layer + an [[eval-driven-model-selection|eval loop]] gating every model release ([[lovable-vibecodes-at-scale]]); [[omni]] built its analytics platform with **99% of code written by [[claude-code]]**; [[claude-design]] extends the plain-language→production idea to visual design. Anthropic's own framing ([[gtm-engineering-anthropic]]): a no-code AE shipped a real tool, the [[ai-native-engineering-org|role-blurring]] this enables.
