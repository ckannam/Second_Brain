# VPS (Virtual Private Server)

A rented always-on cloud server (Hostinger is the recurring pick) used to run agents 24/7 without a dedicated Mac mini — e.g. [[clawdbot]] with a gateway + tunnel ([[set-up-clawdbot-vps]]). One approach to [[hosting-ai-agents]]; alternative: [[trigger-dev]].
