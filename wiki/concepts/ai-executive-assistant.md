# AI Executive Assistant

A personal AI assistant built on [[claude-code]] (or [[clawdbot]]) that knows your business, follows your systems, and gets smarter over time — not a generic chatbot.

## Build pattern (4 phases, [[turn-claude-code-executive-assistant]])
1. Set up the project → 2. Add context & rules (`CLAUDE.md`) → 3. Build first [[claude-code-skills|skills]] & [[claude-code-subagents|sub-agents]] → 4. Let it grow (more skills, memory, context).

## Making it proactive & always-on
- **Proactive** check-ins and building-while-you-sleep: "Klaus" on Clawdbot ([[i-turned-clawdbot-personal-assistant]]).
- **Autonomy** via [[claude-code-scheduled-tasks]] (e.g. a 6am "morning coffee" planning run) and [[claude-code-memory]].
- **Reach:** [[google-workspace-cli]] (email/calendar/docs), [[claude-code-imessage]] / [[claude-code-remote-control]].
