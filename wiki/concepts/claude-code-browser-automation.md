# Claude Code Browser Automation

[[claude-code]] driving a web browser to complete tasks. Now a first-party feature, not a workaround.

## Official built-in browser (July 2026)

Shipped in **v2.1.202–v2.1.206** (Week 28, July 6–10 2026) as an in-app browser panel on Claude Code Desktop. Claude can pull up docs, designs, or any external site and read, click through, and interact with pages the same way it handles local dev-server previews. The browser is sandboxed and configurable (sessions can be set to persist or not). Safety classifiers review write actions on external sites. (Source: [official Claude Code What's New, Week 28](https://code.claude.com/docs/en/whats-new/2026-w28).)

## Earlier computer use (March 2026)

Computer use came to the Desktop app (Week 13, March 23–27) then to the CLI as a research preview (Week 14, March 30 – April 3). This was the capability [[nate-herk]] discussed in [[build-sell-claude-code-course]] as enabling browser tasks — at that point still in research preview, not the polished built-in browser.

## Claude in Chrome (distinct)

A separate extension (**[[claude-code-computer-use|Claude in Chrome]]**) reached general availability in Week 27 (June 29 – July 3, 2026). It runs in the user's own Chrome with their logins, unlike the Desktop browser pane which uses a clean sandboxed profile.
