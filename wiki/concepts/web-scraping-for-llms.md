# Web Scraping for LLMs

Turning websites into clean, LLM-ready data. Primary tool: [[firecrawl]] via [[mcp|MCP]] ([[turn-any-website-llm-ready-firecrawl]]) — scrape, extract branding, map sites, pull structured data; [[claude-code]] self-corrects and can run [[parallel-agents]]. Feeds [[rag|RAG]] and [[agentic-workflows]].
