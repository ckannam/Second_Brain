# Buckets

Life-area **Maps of Content (MOCs)** — the current top-level way of organizing everything
in the vault by the main aspects of life. Each bucket is a **hub note that links to**
relevant pages across `wiki/`, `crm/`, `tasks/`, and `journal/`; it does **not** hold or
move those pages.

> **This is a re-cuttable overlay, by design.** The set of buckets — and the whole idea of
> organizing by life-area — is expected to change over time. Because buckets only *link*,
> they can be renamed, split, merged, or replaced at any point without touching a single
> underlying page. See the **Buckets** section of `AGENTS.md`.
